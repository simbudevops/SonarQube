STEP 2: SonarQube Server

docker run -d --name sonarqube -p 9000:9000 sonarqube:lts-community

Check:

docker ps

Access:

http://<SONARQUBE-SERVER>:9000

Create a SonarQube token from SonarQube security settings.

Never store the token in this repository.

sonar-server

http://<SONARQUBE-SERVER>:9000
